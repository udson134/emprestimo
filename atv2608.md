# Trabalho de Laboratório
## 1. Escolha das decisões
a. Decisão reversível: hospedagem local para hospedagem sem servidor.

b. Decisão irreversível: fato de apenas o técnico realizar o empréstimo.


## 2. Situação nos dois eixos

a. Hospedagem em servidor / ágil
Alto custo e baixa incerteza
Hospedagem em servidor é ligeiramente simples de executar, porém é necessária a aquisição de equipamentos para tal || ou hospedar em nuvem.

b. Apenas o técnico realizar o empréstimo
Alto custo e alta incerteza — Quadrante especial (provável protótipo descartável)
Todo o sistema de autenticação e login deveriam ser criados, provavelmente uma mudança nos atributos da tabela clientes devem ser alteradas também.

c. Em razão dessa alteração seria necessário uma alteração da interface para mostrar apenas as informações do usuário.
Baixa incerteza e alto custo — Cascata
Trabalho que uma vez já foi realizado, apenas deveria ser criada novas abas e interface moldada apenas pro usuário.

## 3. O que muda no que será feito amanhã

1. Caso reversível: hospedagem em nuvem ou criação de um servidor para hospedar a aplicação.
2. Caso irreversível: provável refatoração total do banco de dados dos alunos e criação de um sistema de login e credenciais // nova interface também será necessária.
